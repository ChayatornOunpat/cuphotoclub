Finding an albumค้นหาอัลบั้ม

#

Search by title, category, style or visibility. Sort by newest, last modified, oldest, title or category. Switch between List and Cards view, and set how many show per page. ค้นหาจากชื่อ หมวดหมู่ สไตล์ หรือสถานะการมองเห็น เรียงตามใหม่สุด แก้ไขล่าสุด เก่าสุด ชื่อ หรือหมวดหมู่ สลับมุมมอง List กับ Cards และตั้งจำนวนต่อหน้าได้

Creating oneสร้างอัลบั้มใหม่

#
  1. + New album. Give it a title and a category. Categories are free text — start typing and either pick an existing one or create a new one.กด + New album ใส่ชื่อและหมวดหมู่ หมวดหมู่พิมพ์เองได้ เลือกจากที่มีอยู่หรือสร้างใหม่
  2. Write the excerpt — the one or two lines shown under the title in lists. Add a location if it helps.เขียน excerpt คือคำโปรยหนึ่งถึงสองบรรทัดที่แสดงใต้ชื่อในรายการ ใส่ สถานที่ ได้ถ้าต้องการ
  3. Set both dates. Date is what readers see (for example "March 2025"). Published is the real date that orders the Stories feed.ใส่วันที่สองช่อง Date คือวันที่ผู้อ่านเห็น (เช่น "March 2025") ส่วน Published คือวันที่จริงที่ใช้เรียงลำดับในฟีด
  4. Upload photographs. Drag a whole folder in at once — see Uploading images.อัปโหลดภาพ ลากทั้งโฟลเดอร์เข้ามาได้เลย ดูหัวข้อ การอัปโหลดภาพ
  5. Arrange them on the canvas, pick a cover, choose a style.จัดวางภาพบนแคนวาส เลือกภาพปก เลือกสไตล์
  6. Press Preview to see the real public page. When it looks right, set visibility to Public and save.กด Preview เพื่อดูหน้าจริง เมื่อพอใจแล้วเปลี่ยนสถานะเป็น Public แล้วบันทึก

Display stylesรูปแบบการแสดงผล

#

Set once and forget. Each one lays the same photos out differently on the public page. ตั้งครั้งเดียวจบ แต่ละแบบจัดวางภาพชุดเดียวกันต่างกันบนหน้าเว็บจริง

Styleสไตล์ Looks likeลักษณะ Best forเหมาะกับ
Essay Full bleed, narrative flowภาพเต็มขอบ ไหลไปตามเรื่อง A story with a beginning and an endชุดภาพที่มีลำดับการเล่าเรื่อง
Sticky Fixed layout, tight gridเลย์เอาต์ตายตัว กริดแน่น Consistent, orderly setsชุดภาพที่เป็นระเบียบสม่ำเสมอ
Contact Dense grid, filmstripกริดถี่ แบบฟิล์มสตริป Showing many frames quicklyโชว์ภาพจำนวนมากอย่างรวดเร็ว
Darkroom Black wall, one print at a timeพื้นดำ ทีละภาพ Work that deserves full attentionงานที่ต้องการให้จดจ่อทีละภาพ
Chapters Justified rows, split into chaptersแถวจัดเต็มบรรทัด แบ่งเป็นตอน Built for 100+ photosออกแบบมาสำหรับภาพ 100 ภาพขึ้นไป

Any album can also be set to render on a black wall like Darkroom, keeping its own layout. อัลบั้มไหนก็ตั้งให้แสดงบนพื้นดำแบบ Darkroom ได้ โดยยังใช้เลย์เอาต์เดิม

The canvasแคนวาส

#
  • Palette chips — click an uploaded photo to drop it into the current row, or drag it where you want it.แถบภาพ — คลิกภาพที่อัปโหลดแล้วเพื่อวางลงแถวปัจจุบัน หรือลากไปวางตำแหน่งที่ต้องการ
  • Auto-fill — select many photos at once and let the editor build the rows for you. Smart layout uses each image's shape to choose the rows.Auto-fill — เลือกภาพทีละหลายภาพแล้วให้ระบบจัดแถวให้ ส่วน Smart layout จะดูสัดส่วนภาพในการจัดแถว
  • Cover — the radio button you select. It is the image used on the homepage and in lists.ภาพปก — คือภาพที่เลือกปุ่มกลม ใช้แสดงบนหน้าแรกและในรายการ
  • Cell name — a label for editors only. It is never shown on the public page.Cell name — ชื่อกำกับสำหรับคนทำงานเท่านั้น ไม่แสดงบนหน้าเว็บสาธารณะ
  • Chapter separators (Chapters style) — drop one between rows. Its text becomes the chapter title, and every image after it belongs to that chapter until the next separator.ตัวคั่นตอน (สไตล์ Chapters) — วางไว้ระหว่างแถว ข้อความในนั้นจะกลายเป็นชื่อตอน และภาพที่อยู่หลังจากนั้นจะอยู่ในตอนนั้นจนกว่าจะเจอตัวคั่นถัดไป
Carefulระวัง

Recalculate layout and Clear placed images rebuild the canvas and throw away your arrangement. Deleting an album cannot be undone. Recalculate layout และ Clear placed images จะจัดแคนวาสใหม่และลบการจัดวางเดิมทิ้ง ส่วนการลบอัลบั้มกู้คืนไม่ได้
