Membersสมาชิก

#

/admin/members

The public members page: staff and member listings, profile photos, and the intro text at the top. หน้าสมาชิกสาธารณะ ทั้งรายชื่อทีมงานและสมาชิก ภาพโปรไฟล์ และข้อความแนะนำด้านบน

  • Members page intro — the paragraph above the directory. It has its own Save intro button.ข้อความแนะนำ — ย่อหน้าเหนือรายชื่อ มีปุ่ม Save intro แยกของตัวเอง
  • Member directory — add, edit and remove people.รายชื่อสมาชิก — เพิ่ม แก้ไข และลบรายชื่อ
  • Drag rows to reorder them. The order you set is the order visitors see, within the view you are currently looking at.ลากแถวเพื่อจัดลำดับ ลำดับที่จัดไว้คือลำดับที่ผู้เข้าชมเห็น ภายในมุมมองที่กำลังเปิดอยู่
Not the same as admin accountsคนละอย่างกับบัญชีผู้ดูแล

This page is a public listing — names and photographs on the website. It does not give anyone access to the admin. For that, see Admin accounts. หน้านี้เป็นรายชื่อสาธารณะ คือชื่อและภาพที่แสดงบนเว็บ ไม่ได้ให้สิทธิ์เข้าระบบหลังบ้าน ถ้าต้องการแบบนั้นดูที่ บัญชีผู้ดูแล

Contact messagesข้อความติดต่อ

#

/admin/messages

Everything sent through the public contact page arrives here. Messages can be archived once handled, and archived ones have their own view. ข้อความที่ส่งผ่านหน้าติดต่อสาธารณะจะมาที่นี่ จัดการแล้วเก็บเข้าคลังได้ และดูข้อความที่เก็บไว้ในมุมมองแยกต่างหาก

Nothing reminds you to check itไม่มีอะไรเตือนให้เข้ามาดู

There is no dashboard card for this page. Make it part of someone's weekly routine, or people who write in will be ignored. หน้านี้ไม่มีการ์ดบนแดชบอร์ด ควรมอบหมายให้ใครสักคนเช็กเป็นประจำทุกสัปดาห์ ไม่งั้นคนที่เขียนเข้ามาจะถูกปล่อยทิ้ง
