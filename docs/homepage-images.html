Hero background imagesภาพพื้นหลังหน้าแรก

#

/admin/hero-images

A pool of images for the top of the homepage. The system picks one at random on every page load — so every image here should be able to carry the front page on its own. Press Add Images to upload new ones or select from the library. คลังภาพสำหรับส่วนบนสุดของหน้าแรก ระบบจะสุ่มหยิบหนึ่งภาพทุกครั้งที่เปิดหน้า ดังนั้นทุกภาพในนี้ต้องดีพอที่จะเป็นหน้าแรกได้ด้วยตัวเอง กด Add Images เพื่ออัปโหลดใหม่หรือเลือกจากคลัง

History & Clubroomภาพประวัติและห้องชมรม

#

/admin/landing-images

Two fixed photographs, each with its own Save button: ภาพสองภาพที่ตายตัว แต่ละภาพมีปุ่มบันทึกแยกกัน:

  • Our History — the archival photograph in section 03.Our History — ภาพจากคลังเก่าในส่วนที่ 03
  • Clubroom — the portrait-crop, monochrome photograph in section 04.Clubroom — ภาพแนวตั้งขาวดำในส่วนที่ 04
Save each one separatelyบันทึกทีละภาพ

Picking an image is not enough — press Save inside that section. Until you do, the site keeps showing the old image. แค่เลือกภาพยังไม่พอ ต้องกด Save ในส่วนนั้นด้วย ถ้ายังไม่กด เว็บจะยังแสดงภาพเดิม

The preview on each page matches the crop and tone used on the real landing page, so what you see is what visitors get. ตัวอย่างในหน้านี้ใช้การครอปและโทนสีเดียวกับหน้าแรกจริง สิ่งที่เห็นคือสิ่งที่ผู้เข้าชมจะเห็น
