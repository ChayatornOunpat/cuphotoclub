Uploading imagesการอัปโหลดภาพ

The same uploader appears in albums, posts, activities and the image picker. Drag files onto it or click to browse. ตัวอัปโหลดตัวเดียวกันนี้ใช้ในอัลบั้ม บทความ กิจกรรม และหน้าเลือกภาพ ลากไฟล์มาวางหรือคลิกเพื่อเลือกไฟล์

What it acceptsรับไฟล์แบบไหน

#
  • Accepted: JPG, PNG, WebP and HEIC, with a size limit per file shown on the uploader itself.รองรับ: JPG, PNG, WebP และ HEIC โดยมีขนาดสูงสุดต่อไฟล์แสดงอยู่บนตัวอัปโหลด
  • Everything is converted to WebP before it is stored. The resize toggle controls whether large images are also shrunk — not the format.ทุกไฟล์จะถูกแปลงเป็น WebP ก่อนจัดเก็บ ส่วนปุ่มย่อขนาดคุมแค่ว่าจะย่อภาพใหญ่ด้วยหรือไม่ ไม่ได้คุมฟอร์แมต
  • Keep working while it uploads. Drag more files in mid-upload and they queue behind the current batch.ทำงานต่อได้ระหว่างอัปโหลด ลากไฟล์เพิ่มระหว่างที่ยังอัปโหลดอยู่ ไฟล์ใหม่จะเข้าคิวต่อจากชุดปัจจุบัน
  • Nothing is dropped silently. Files that cannot be uploaded — over the limit, or the slot only takes one file — are reported back as skipped.ไม่มีไฟล์หายเงียบ ๆ ไฟล์ที่อัปโหลดไม่ได้ เช่น เกินขนาดหรือช่องนั้นรับได้ไฟล์เดียว จะถูกรายงานว่าข้ามไป
Upload the full-size fileอัปโหลดไฟล์ขนาดเต็ม

Do not shrink photos in Lightroom or Photoshop first. The uploader compresses better than exporting twice does, and a file that has already been squeezed cannot get its quality back. ไม่ต้องย่อภาพใน Lightroom หรือ Photoshop มาก่อน ตัวอัปโหลดบีบอัดได้ดีกว่าการเอ็กซ์พอร์ตสองรอบ และไฟล์ที่ถูกบีบมาแล้วกู้คุณภาพคืนไม่ได้

The image pickerหน้าเลือกภาพ

#

Wherever you can upload, you can usually also select an existing image instead of uploading a duplicate. The picker sorts by name or date and lets you change the preview size. ที่ไหนที่อัปโหลดได้ ส่วนใหญ่จะ เลือกภาพที่มีอยู่แล้ว ได้ด้วย แทนที่จะอัปโหลดซ้ำ หน้าเลือกภาพเรียงตามชื่อหรือวันที่ และปรับขนาดตัวอย่างได้

Choosing an existing image costs no extra storage. Uploading the same photograph twice does — see Storage & cost. การเลือกภาพที่มีอยู่แล้วไม่กินพื้นที่เพิ่ม แต่การอัปโหลดภาพเดิมซ้ำกินพื้นที่ ดูที่ พื้นที่และค่าใช้จ่าย
