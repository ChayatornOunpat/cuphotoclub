Largest filesไฟล์ขนาดใหญ่

#

/admin/largest-files — reached from Storage & Cost— เข้าจากหน้า Storage & Cost

The biggest files, each showing what points at it. That matters: a file used by a published album is not safe to remove. ไฟล์ที่ใหญ่ที่สุด พร้อมบอกว่า มีอะไรอ้างถึงไฟล์นั้นบ้าง สำคัญมาก เพราะไฟล์ที่อัลบั้มที่เผยแพร่แล้วใช้อยู่ ลบไม่ได้

  • If nothing points at it, it is an orphan and safe to clear out.ถ้า ไม่มีอะไรอ้างถึง แปลว่าเป็นไฟล์กำพร้า ลบออกได้
  • If something does, moving it to trash removes it from those places too. Read the list first.ถ้ามีอะไรอ้างถึงอยู่ การย้ายไปถังขยะจะ ทำให้หายจากที่เหล่านั้นด้วย อ่านรายการให้ดีก่อน
  • Trash is reversible. The file stays until you purge it.ถังขยะกู้คืนได้ ไฟล์จะยังอยู่จนกว่าจะกดล้างถัง

R2 ImagesR2 Images

#

/admin/r2-images

The full bucket inventory and orphaned-file cleanup. Useful when you need to find a specific file, or tidy up after deleting a lot of content. รายการไฟล์ทั้งหมดในที่เก็บ และเครื่องมือล้างไฟล์กำพร้า ใช้ตอนต้องหาไฟล์ใดไฟล์หนึ่ง หรือเก็บกวาดหลังลบเนื้อหาจำนวนมาก

Never delete from Cloudflare directlyอย่าลบจาก Cloudflare โดยตรง

Always remove files through these admin pages, never from the Cloudflare dashboard. The site keeps its own index of what is in storage; deleting behind its back makes every number on this page wrong until someone re-syncs it. ลบไฟล์ผ่านหน้าระบบหลังบ้านเท่านั้น อย่าลบจากหน้า Cloudflare เพราะเว็บมีดัชนีของตัวเองว่ามีไฟล์อะไรอยู่บ้าง ถ้าลบลับหลัง ตัวเลขในหน้านี้จะผิดทั้งหมดจนกว่าจะซิงก์ใหม่
